# Perfiles geológicos (PWA)

Secciones geológicas en el navegador, sin instalar nada: traza sobre imagen satelital y DEM, importa la
geología de cartas (SHP, KML/KMZ, GeoJSON, CSV, DEM GeoTIFF), corta y proyecta contactos, fallas, ejes y
manteos, construye en profundidad (kink, Busk, capas paralelas), modela (trishear, flujo paralelo a la
falla, cizalla inclinada, inversión trishear) y exporta lámina SVG/PNG/PDF y datos KMZ 3D, SHP 3D,
GeoJSON, CSV y DXF.

**Abrir:** https://cvenegas-sernageomin.github.io/perfiles-geologicos-pwa/

Funciona sin conexión una vez instalada (con «⤓ Zona» se guardan DEM e imagen de la zona de trabajo).

Este repositorio solo publica la aplicación; el código fuente, las pruebas y la documentación viven en
un repositorio aparte.

Datos de terceros: DEM AWS Terrain Tiles / Mapzen; imágenes Esri World Imagery y Sentinel-2 cloudless
